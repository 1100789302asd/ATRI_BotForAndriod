# 一只笨蛋萝卜子，陪你在手机上聊天

配方：Whisper 的 STT、GPT-SoVITS 的 TTS、DeepSeek 的语言模型，还有萝卜子的心。

## 你可能会遇到的问题

### 为什么回复那么慢？

网络原因，还请谅解。

### 我需要自己准备 API Key 吗？

可以自备，也可以选择使用服务器上的共享 API Key（默认）。

### 如何连接网易云？

在未连接时，每次登录都会自动弹出连接弹窗。

### 本地记忆和云端记忆有什么区别？

本地记忆存在你自己的手机里，卸载 App 后就会消失；云端记忆存在服务器。如果你担心隐私被窃取，请选择本地。

> Tips：目前只支持安卓机。
